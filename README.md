# Flows Example Demos

1. Clone the repo into your computer
2. Run `docker-compose up -d` to setup the demo environment
3. Enter the container
4. Run `composer install`
5. Run composer setup script to create sqlite3 database
6. Run the demos inside the `App` directory with `php App/[demo-file-name].php`. A brief explanation of the demo is shown on execution.
7. **Fiddle with the code**

Constructive feedback and criticism is welcome!

This is work in progress, have fun with it. :)

Flows framework available [here](https://github.com/sousarmb/flows) and on [packagist](https://packagist.org/packages/rsousa/flows)
